# Lift B3b1 (practice Sim Lab on phones) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** At phone width, practice Sim Lab (start screen, rounds, verdict) and Sim Lab questions inside the full exam look and flow like the approved June E2E drawing, with no engine, scoring or gating change.

**Architecture:** Two new eager `defer` modules. `features/ios-sheet.js` owns the in-app confirm sheet (B2's `_examSheet`, moved) and a new enlarge sheet. `features/ios-simlab.js` owns the phone-only Sim Lab pieces: pure model/view pairs for the start screen and the verdict, plus mount hooks that `features/sim-lab.js` calls only when a caller passes `opts.lift` on a phone. The round itself is mostly CSS in a new `lift-ios.css` section scoped to `#page-sim-lab.isl-practice` and `#page-exam .exam-pbq`. The start screen drives the real (hidden) `#sle-*` buttons, so mode, rounds, gates and the free daily session stay exactly today's.

**Tech Stack:** Vanilla JS (IIFE, `window` exports), CSS in `lift-ios.css` (whole file loads only at `max-width: 899px`), UAT (`tests/uat/*.js`, vm sandbox via `_fnBody`), Playwright.

**Spec:** `docs/superpowers/specs/2026-10-22-ios-lift-b3b1-design.md` (approved; updated 22 Oct with the rebuilt start screen and copy). E2E: `feat/cert-ios-e2e` `mockups/cert-ios-simlab.html` @ `ac0d9180`+ (states `entry`, `loading`, `round`, `reset`, `round-map`, `enlarge`, `verdict`, `verdict-open`) and `mockups/cert-ios-exam.html?v=pbq`.

## Global Constraints

- Phone only (`max-width: 899px`). Desktop renders exactly as today: every new code path checks the media query, and desktop UAT/E2E stay green.
- `app.js` stays at its 8301-line ratchet. New code goes in `features/`.
- No inline `on*=` handlers in `index.html` or rendered HTML (Sec-P7). Taps go through `data-act` delegation or `addEventListener`.
- Escape every scenario-derived string in new markup (`escHtml`/`_esc`).
- Copy is the approved drawing plus today's strings, exactly:
  - Start: "Sim Lab" / "Practice the hands-on PBQs"; lede "The exam opens with them. Run a few back to back and the format stops being a surprise."; "Relaxed, a count-up timer." / "One clock, flag and return."; eyebrows "Mode", "Length"; "rounds"; cap line `Free covers <b>one Sim Lab session a day</b>. 10 rounds, the exam length, needs Pro.`; Start "Start the sim" (Exam: "Start exam sim") with `<N> rounds`; practice summary "Practice mode, mixed topics, a count-up timer."
  - Loader: "Building round N of M…" over today's sub line "A fresh scenario. This takes a few seconds."
  - Reset sheet: title "Start this PBQ again?", body "Your answers on this question will be cleared.", go "Clear answers", stay "Keep them".
  - Verdict: eyebrow "Sim Lab · M rounds", headline "N of M passed.", "X of Y steps right.", "Your rounds", Right / Partly / Wrong, "Where you slipped" + today's `_slWeakCluster` line, "Back to Practice", free upsell "Go Pro for exam-length runs".
  - Enlarge: "Tap to enlarge", "Close", hint "Scroll to look around. Swipe down or tap Close to go back."
- No em-dashes and no arrow glyphs in new phone labels.
- Scope guard: round restyling only under `#page-sim-lab.isl-practice`; Sim Lab Exam mode (B3b2) and Decision Lab look as today (Exam mode loses only the app top bar and tab bar).
- CSS class prefix `isl-`. Motion is BRAND §6: `--ios-ease`, enter 360ms / exit 200ms for sheets, press `scale(0.97)` (rows `0.99`), `transform`/`opacity` only, hover gated `(hover:hover) and (pointer:fine)`, reduced motion fades only.
- Touch targets ≥ 44px, including the Tap to enlarge and Reset pills (hit-area `::after`).
- Ship as v8.188.0 only on the founder's "ship it".

## Review Focus

1. **A round ends while the Reset sheet is open** (Submit tapped from the keyboard, or a time-up in the exam): the sheet closes as "Keep them" and the next round never inherits a pending clear. (Task 4 test.)
2. **Free user taps the locked 10 or the Exam card on the phone start screen:** today's Pro gate opens and the picked mode/rounds don't change. (Task 3 test.)
3. **Reference kinds that are answer surfaces** (terminal `excerptLines`, faceplate `facePorts`, wiremap `wiremapPins`): never get an enlarge button and still take answers inline. (Task 4 test.)
4. **Scenario text with `&`, `<`, `<mark>`** in titles, topics and the slip line: escaped in the verdict, `<mark>` kept only where today keeps it. (Task 5 UAT.)
5. **Desktop and Decision Lab untouched:** at 1280 the entry, round and verdict DOM are today's; Decision Lab's mount (no `opts.lift`) gets no hooks. (Tasks 3 to 5 tests.)
