# Lift B3c1 (Reword Gauntlet on phones) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** At phone width, the Reword Gauntlet's entry, run and results look and flow like the approved E2E drawing, with no change to generation, the quality gate, scoring, history, the cracked list, the free daily run or its gate.

**Architecture:** A new eager `defer` module, `features/ios-gauntlet.js`, holds pure model/view pairs (entry, result), the topic sheet host (`#igt-topics`) and `iosGauntlet.isPhone`. `features/flagship-drills.js` calls them from `renderGauntletEntry` and `renderGauntletResult` on phones only; desktop keeps today's markup. The run stays the Lift A quiz: CSS in a new `lift-ios.css` section hides the Lift A pill row while `#gauntlet-ladder` shows and restyles the ladder.

**Tech Stack:** Vanilla JS (IIFE, `window` exports), CSS in `lift-ios.css` (phone only), UAT (`tests/uat/*.js`, vm sandbox via `_fnBody`), Playwright.

**Spec:** `docs/superpowers/specs/2026-10-23-ios-lift-b3c1-design.md` (approved; amended `50b01902`). E2E: `feat/cert-ios-e2e` `mockups/cert-ios-gauntlet.html` @ `048d3d63`, states `entry`, `entry-pick`, `entry-free`, `loading`, `run`, `run-answered`, `result-cracked`, `result-miss`, `result-miss-open`, `result-miss-free` (founder approved in the Simulator, 23 Oct).

## Global Constraints

- Phone only (`max-width: 899px`). Desktop Gauntlet renders and behaves exactly as today.
- `app.js` stays at its 8301-line ratchet; no inline `on*=` (Sec-P7); `data-act` delegation or `addEventListener`.
- Escape every topic, concept, question, option, hinge and explanation string; the hinge mark goes on after escaping (escape-then-highlight), and only when the escaped hinge is found in the escaped question.
- Copy, exactly (today's strings plus the drawing's):
  - Entry: title "Reword Gauntlet" (no sub line); headline `Beat the concept in <em>every</em> disguise`; lede "Five questions on one concept. The wording never repeats."; "Today's target"; why "Your pick" / "Your weakest topic right now" / "A good place to start"; "Pick a different topic"; `<b>N</b>` + "concepts cracked so far." / "Each one survived all five wordings." (N > 0 only); section "The five wordings"; rungs Plain · Scenario · Best-of · Not-trap · Twisted; free only `Free covers <b>one Gauntlet a day</b>, on top of your 15 questions.`; dock "Start the Gauntlet".
  - Topic sheet: title "Pick a topic"; the cert's `TOPIC_DOMAINS` keys; current one ticked.
  - Results kicker "Reword Gauntlet · <topic>". Cracked: "Concept cracked", the concept, "Five wordings, five answers. <b>That's N in your collection.</b>" or "Took N runs. <b>Earned.</b>", "Streak +1 · 5 questions toward today's goal", dock "Next target" · "Back to Drills" / "Back to Home". Missed: `Cracked <em>N of 5</em>`, today's callout (`The <b>X</b> got you. One rung from the seal.` / `The <b>X</b> and the <b>Y</b> got you.` / `N rungs got you this time.`), section "Your five wordings", rows rung name + description + "Right" / "Wrong", opened: the wording, "Your answer", "Answer" (wrong rows only), the explanation; "Run it again and every question is re-worded from scratch. There's nothing to memorize. That's the point."; dock "Run it again" · "Different concept".
  - Free user after today's run (both results): foot note "That was today's free run. The next one is free tomorrow, or Pro runs it again now."
- No em-dashes and no arrow glyphs in new phone labels ("Next target", not "Next target →").
- CSS prefix `igt-`. Plain top padding, never `env(safe-area-inset-top)`. Motion BRAND §6 and the stage-2 decisions: entry and results reveal once; the sheet is the B3b1 sheet (enter 360ms, exit 200ms, `--ios-ease`, fade only under reduced motion); a topic tap closes the sheet 140ms later; the ladder's live rung grows with `transform: scaleY`, never `height`; rows open in 220ms, close instantly; press `scale(0.97)` (rows `0.99`); hover gated.
- Touch targets ≥ 44px (Pick a different topic, topic rows, result rows).
- Ship as v8.190.0 only on the founder's "ship it".

## Review Focus

1. **A free user taps Start a second time today:** today's gate opens, the entry stays, nothing is consumed. (Task 2 test `free second Start opens the gate and keeps the entry`.)
2. **Scenario text with `&`, `<` and a hinge containing `&`:** escaped everywhere; the hinge is marked only where it matches. (Task 1 UAT.)
3. **The forge misfires** (generation throws): back on the phone entry with today's toast, and Start works again. (Task 2 test `a misfire returns to the phone entry`.)
4. **A normal quiz right after a Gauntlet:** the Lift A pills are back and the ladder is hidden. (Task 3 test `a normal quiz after a Gauntlet shows the pills`.)
5. **The topic sheet is open when the page changes** (back, Start): it closes and never reappears. (Task 2 test `leaving the entry closes the topic sheet`.)
