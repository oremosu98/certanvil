# AI-900 → AI-901 swap (+ catalogue fixes)

**Agreed 2026-10-08.** Microsoft retired AI-900 on 2026-06-30 and replaced it with
**AI-901: Microsoft Azure AI Fundamentals** (same credential name). This plan swaps
the `ai900` cert to AI-901 and then closes the smaller catalogue gaps found the same day.

## Founder decisions (2026-10-08)

1. **Keep the internal id `ai900`.** It now means "Azure AI Fundamentals" (the
   credential Microsoft kept). Everything user-visible says AI-901. No data
   migration, no DNS change, `ai.certanvil.com` stays. Renaming would orphan
   `sr.ai900`, `activated.ai900`, `readiness_snapshots.ai900`, `cert_results.ai900`,
   `drill_stats.ai900` and `freeCertId:'ai900'` users.
2. **Questions may include short Python / Foundry SDK snippets** (3–6 lines,
   minority of items) — the exam page requires Python syntax and SDK familiarity.
3. **Decision Lab is hidden for the AI cert** now; its 50 draft AI-900 scenarios are
   rebuilt for AI-901 after the question bank (Phase 4).
