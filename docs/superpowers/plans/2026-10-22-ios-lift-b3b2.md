# Lift B3b2 (Sim Lab Exam mode on phones) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** At phone width, Sim Lab's Pro Exam mode (loader, rounds, End dialog, Abandon sheet, results) looks and flows like the approved E2E drawing, with no engine, scoring, clock, generation or gating change. On every width, the Pace card's target stops reading "Target NaN:NaN", and a time-up exam reads "Out of time".

**Architecture:** Exam rounds keep running in `features/sim-lab.js`, which gains phone-only branches behind `iosSimLab.isPhone()`. `features/ios-simlab.js` owns everything phone-shaped: pure model/view pairs (exam bar, dock, End dialog, exam verdict with pace) and two hosts. The first host is the exam bar (`iosSimLab.examBar`), which moves the real `#sl-clock-slot` into it so `_slTickClock` keeps driving the same clock. The second is the End dialog (`iosSimLab.openEnd/closeEnd`), a body-level `#isl-end` whose markup mirrors B2's `#exam-modal`, so B2's dialog CSS is reused by widening its selectors. Everything is scoped to `#page-sim-lab.isl-exam`, which `_slSetPractice` toggles opposite `isl-practice`.

**Tech Stack:** Vanilla JS (IIFE, `window` exports), CSS in `lift-ios.css` (whole file loads only at `max-width: 899px`), UAT (`tests/uat/*.js`, vm sandbox via `_fnBody`), Playwright.

**Spec:** `docs/superpowers/specs/2026-10-22-ios-lift-b3b2-design.md` (approved; amended `b04b7de9`). E2E: `feat/cert-ios-e2e` `mockups/cert-ios-simlab.html` @ `66dd1c77`, states `exam-loading`, `exam-round`, `exam-round-last`, `exam-end`, `exam-end-jump`, `exam-abandon`, `exam-result`, `exam-result-timeup` (founder approved in the Simulator, 22 Oct).

## Global Constraints

- Phone only (`max-width: 899px`) apart from the two pace fixes. Desktop Exam mode keeps the palette, today's footer, `_slRenderReview` and both `confirm()`s. Practice Sim Lab (B3b1) and Decision Lab look and behave as today.
- `app.js` stays at its 8301-line ratchet. No inline `on*=` (Sec-P7): wire through `addEventListener` or `data-act` delegation. Escape scenario-derived strings in new markup.
- Copy, exactly (drawing plus today's strings):
  - Loader (phone): "Building your exam…" over "Every round is built before your clock starts."
  - Bar: "Time left"; "Round N of M"; "K answered"; "End".
  - Dock: "Flag" / "Flagged"; "Next"; last round "Review"; ‹ has `aria-label="Previous round"`.
  - End dialog: eyebrow "Sim Lab exam · end of session"; title `Submit <em>exam?</em>`; "Answered" / "Skipped" / "Flagged"; "Review the N you skipped first" / "Review the N you flagged first"; "Submit and see results"; "Abandon exam"; "Jump to a round"; key "Answered" / "Skipped" / "Flagged".
  - Abandon sheet (`iosSheet`): title "Abandon this exam?", body "Your answers won't be scored.", stay "Keep going", go "Abandon".
  - Results: kicker "Sim Lab exam · M rounds" or "Time's up · M rounds"; "N of M passed."; "X of Y steps right."; "Pace"; pill "On exam pace" or "Out of time" (phone: no ✓); coaching "m:ss to spare. On the real exam that leaves room to revisit a hard PBQ." or "Round N ran long. On test day that's the round to triage: flag it and move."; "Target m:ss"; "0:00" / "your time m:ss"; per-round "Round N · <topic>" with time and "par m:ss"; "Your rounds"; "Back to Practice". No upsell in exam mode.
- No em-dashes and no arrow glyphs in new phone labels (the Next arrow is an SVG, as drawn).
- CSS prefix `isl-` (B2 `ix-` classes reused only inside the End dialog). Plain top padding, never `env(safe-area-inset-top)` (v8.188.1, v8.188.3).
- Motion is BRAND §6 and the stage-2 decisions: the End dialog reuses B2's `ix-fade`/`ix-pop` (260ms in, 200ms out, from `scale(0.96)`, fade only under reduced motion). While the Abandon sheet is up the dialog box sits at `scale(0.98)` (the sheet's scrim already dims it). Exam rounds get no `isl-enter`. The low clock is amber (`--accent-deep`), never red. Press `scale(0.97)`, `transform`/`opacity` only, hover gated.
- Touch targets ≥ 44px (End pill, dock buttons, grid squares).
- Ship as v8.189.0 only on the founder's "ship it".

## Review Focus

1. **The clock runs out while the End dialog or the Abandon sheet is open:** both close, results show "Time's up · M rounds" and "Out of time", and tapping Abandon on a sheet that resolves afterwards does nothing. (Task 4 test `time-up closes the dialog and the sheet`.)
2. **Time spent in the End dialog:** it counts towards no round. Jumping from the grid restores that round's answers. (Task 4 test `dialog time is not counted; a jump restores answers`.)
3. **A practice session after an exam (and an exam after practice):** `isl-exam` is gone, the clock slot is back in the top bar, the bar and dock are removed, and the practice timer shows. (Task 4 test `exam then practice leaves no exam chrome`.)
4. **Counts include the round in view:** answer the last round, flag it, tap Review, and the dialog says that round is answered and flagged. (Task 4 test `counts include the round in view`.)
5. **Abandon, then Keep going:** the dialog stays open and works, and Escape while the sheet is up closes only the sheet. Abandon itself stops the clock, so no results page appears a minute later. (Task 4 test `abandon asks; Keep going keeps; Abandon leaves for good`.)
