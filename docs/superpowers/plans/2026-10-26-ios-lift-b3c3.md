# Lift B3c3 (Decision Lab and its Exam-style on phones) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** At phone width, Decision Lab's entry, practice run, Exam-style run and results look and flow like the approved E2E drawing, Leave and Back work at every width, and nothing changes in the bank, scoring, free cap, Pro gates or weak-spot recording.

**Architecture:** A new eager `defer` module, `features/ios-decisionlab.js`, holds pure model/view pairs (entry, results) and hosts (`#idl-entry` new, `#dl-result-root`). `features/sim-lab.js` (Decision Lab section) hands phones to it, docks the round's Submit and the post-grade Next, and drives Exam-style through the B3b2 exam bar and End dialog in `features/ios-simlab.js`, which gain options so Decision Lab can reuse them while Sim Lab's own output stays byte-identical. A new `decisionLabExit` fixes the dead Leave / Back everywhere.

**Tech Stack:** Vanilla JS (IIFE, `window` exports), CSS in `lift-ios.css` (phone only), UAT (`tests/uat/*.js`, vm sandbox via `_fnBody`), Playwright.

**Spec:** `docs/superpowers/specs/2026-10-26-ios-lift-b3c3-design.md` (approved; review fixes `bf1f76f3`). E2E: june-e2e `mockups/cert-ios-decisionlab.html` @ `a4c9e128`, states `entry`, `entry-free`, `practice`, `practice-graded`, `exam`, `exam-amber`, `exam-end`, `results`, `results-open`, `results-exam-timeup`, `leave` (founder approved in the Simulator, 25 Oct).

## Global Constraints

- Phone only (`max-width: 899px`). Desktop Decision Lab renders and behaves as today, except Leave (runner) and Back (results) now work through `decisionLabExit` (no sheet on desktop).
- `app.js` stays at its 8301-line ratchet; no inline `on*=` (Sec-P7); `data-act` delegation or `addEventListener`.
- Escape every scenario title, option text, explanation, pair and family string.
- Copy, exactly (spec + drawing):
  - Entry: title "Decision Lab"; free users only the "Pro" lock pill; headline `Make the <em>right call</em>`; lede "Three of four options look right. The buried constraint picks the winner."; "Today's target", value "Mixed services", sub the cert (`CERT_PACK.meta.name` + code, e.g. "Azure AZ-900"); section "Mode"; cards "Practice" / "Why each wrong option is wrong." and "Exam-style" / "Timed, no feedback till the end." (free: a "Pro" lock tag on Exam-style); section "How many decisions"; count echo `N` + "decisions"; segment 5 · 10 · 20 (free: 20 locked); free only `Free covers <b>one set a day</b>, with the full reasoning on every miss.`; dock "Start the drill" + `N decisions`.
  - Practice run: header ‹ + pill "Decision N of M" + dots; the scenario with the "Scenario" kicker; the step prompt as today; docked "Submit"; after grading the options read "Best" (the right line) and "Your pick" (a wrong pick), others dim, today's per-option "why" lines stay, and today's teach card reads "The tell"; the dock button becomes "Next decision" / "See results". No Flag.
  - Exam-style: the B3b2 bar with "Time left", "Decision N of M", "K answered", End; dots; docked "Submit" ("Submit and see results" on the last decision). End dialog: eyebrow "Decision Lab · Exam-style", title `Submit <em>set?</em>`, counts Answered / Skipped (no Flagged), "Submit and see results", "Abandon set"; no Review button, no Jump. Abandon sheet: "Abandon this set?" / "Nothing from it will count." / Abandon · Keep going.
  - Results: kicker "Decision Lab · Practice · <code>" / "Decision Lab · Exam-style · <code>", or "Decision Lab · Exam-style · Time's up"; title `<em>N of M</em> right calls`; "Look-alikes you still confuse" (rows `<b>A</b> vs <b>B</b>` + "Missed ×N"), "Weak service families" (chips), each only with entries; "Your N decisions" (N spelt as today's number); rows: the scenario `title`, sub the scenario `family`, pill "Right" / "Wrong"; opened analyze rows: "Your pick" (or "No answer"), "Right call", "The tell"; other step types: "The tell"; dock "Run another set", then "Back to Drills" / "Back to Home".
  - Leave sheet (practice): "Leave Decision Lab?", body "Your decisions so far won't count." (Pro) or "Your decisions so far won't count. Today's free set is already used." (free), Leave · Keep going.
- No em-dashes and no arrow glyphs in phone labels.
- CSS prefix `idl-`. Plain top padding. Reveals rest visible and animate from hidden (UAT 481 guard). Motion per BRAND §6 and the visual pass: entry and results reveal once; a new decision swaps with a 150ms opacity fade (no rise), the next dot on the same beat; graded colours 180ms, then the tell fades from `translateY(4px)` over 200ms with an 80ms delay; Submit → Next decision is an instant label swap; the amber clock is a 200ms colour change, no pulse; sheets and the End dialog keep B3b2 timings; rows open in 220ms.
- Touch targets ≥ 44px. Ship as v8.192.0 only on the founder's "ship it".

## Review Focus

1. **Time runs out with the End dialog or the abandon sheet open:** both close and the results show "Time's up" with the unreached decisions as "No answer". (Task 4 test `time-up closes the End dialog and the sheet`.)
2. **Sim Lab Exam mode after the shared changes:** its bar, End dialog (Flagged, Review, Jump) and clock read exactly as before. (Task 4: UAT 502 unchanged and `lift-b3b2.spec.js` green.)
3. **Leaving by the tab bar or Leave mid Exam-style:** the clock stops and a later Decision Lab or Sim Lab session starts clean. (Task 2 test `Leave stops the clock and a new set starts clean`.)
4. **A free user's second set from the results' Run another set:** today's "That's today's free set" gate opens, nothing starts. (Task 5 test `free Run another set opens today's gate`.)
5. **Scenario text with `&` and `<` (titles, options, the tell, pairs):** escaped on the entry and results. (Task 1 UAT.)
