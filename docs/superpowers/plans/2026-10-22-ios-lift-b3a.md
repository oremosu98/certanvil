# Lift B3a (the Drills tab on phones) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** At phone width the Drills tab is the June E2E Drills screen with a "More ways to practise" card, built from real data.

**Architecture:** A phone renderer, `features/ios-drills.js`, turns live app state into plain state, a pure model (`_iosDrillsModel`) and a pure escaped view (`_iosDrillsHtml`), and renders into `#ios-drills`, the first child of `#page-drills`. `lift-ios.css` hides the old cards beside a rendered `#ios-drills`. Taps route by `data-act` to today's entry functions. Same pattern as B1/B2.

**Tech Stack:** Vanilla JS (IIFE, `window` exports), CSS in `lift-ios.css` (media-gated `max-width: 899px`), UAT (`tests/uat/*.js`, vm sandbox via `_fnBody`), Playwright.

**Spec:** `docs/superpowers/specs/2026-10-22-ios-lift-b3a-design.md`. E2E: `feat/cert-ios-e2e` `mockups/cert-ios-drills.html` @ `ab952bb4` (default, `?v=free`, `?v=empty`, `?v=dl`).

## Global Constraints

- Phone only (max-width 899px). Desktop never shows `#page-drills`; nothing outside it changes.
- `app.js` stays at its 8301-line ratchet (UAT 494 asserts it).
- No inline `on*=` handlers in `index.html` or rendered HTML (Sec-P7 ratchet): taps go through one delegated listener on `data-act`.
- Every name and topic in rendered HTML is escaped.
- Copy is exactly the drawn E2E (lists below). No em-dashes, no arrow glyphs in labels.
- Each control calls today's entry, unchanged; Pro gates and free daily caps are not touched.
- CSS class prefix `id-`. Motion: BRAND §6 (`--ios-ease`), press `scale(0.99)` on rows, `transform`/`opacity` only, hover gated `(hover:hover) and (pointer:fine)`.
- Ship as v8.187.0 only on the founder's "ship it".

## Review Focus

1. **Tier not known at first paint** (quota hydrates after the tab first renders): no free/Pro pills or locks until it is known, then they appear without a tap. (Task 3 test.)
2. **A cert with Decision Lab and no Sim Lab** (AZ-900): Decision Lab row present, Sim Lab row absent, Azure domains listed. (Task 2 UAT + Task 3 Playwright.)
3. **Topic or domain names with `&`, `<`** (e.g. "DNS & DHCP"): escaped, never raw HTML. (Task 2 UAT.)
4. **Coming back from a drill** (Gauntlet / Why-Not / a mistakes drill) to Drills: the screen re-renders with fresh counts, and Gauntlet/Why-Not still return to Drills. (Task 3 test.)
5. **A free user tapping a locked row** (Why-Not, or Gauntlet after today's run): today's Pro gate or upsell, never a dead tap. (Task 3 test.)
