Why

  • Same rule as today. Prefix in ink, last glyph in bronze. A+ Core 1 and 2 add a small bronze numeral, so PSM I and II get a bronze roman numeral the same way.
  • Three-letter marks drop a size, exactly like AWS (34px to 27px), so SAI and PSM fit the tile. In SecAI+ the bronze letter is the S, so it never looks like AI-900, where the I is bronze.
  • The Inter marks are plain text, like the hub does now. Both PSM rows show "PSM", the same way both A+ rows show "A+". The row name tells them apart.
  • The new tiles are shown at full strength and the existing ones faded, only so you can compare. In the app they all look the same.

Why

  • Scaled certs keep "684 / 900". The slash means "out of", and that only works when the top of the scale is a real number.
  • Percent certs show "72% · pass 60%" (PSM: "79% · pass 85%"). "Out of 100%" adds nothing, and a percent score means little without the pass mark, which is much higher on PSM than on PRINCE2.
  • The % sign is smaller and lighter (Fraunces 500), as BRAND.md sets for the readiness suffix. The number stays the hero.
  • No score yet shows "--" (two hyphens) in both formats, never "0%". Zero would read as a real, terrible result.
  • The cert code slot says "Scrum.org" for PSM, because "PSM I" would just repeat the name. PRINCE2 has no official exam code, so its slot says "Foundation".

Visual pass notes

The five-stage pass, run in order on this file. BRAND.md outranks every skill.

Stage 1design-taste-frontend

  • Read as an extension inside a locked system, not a new direction. Dials set to match the app (variance 4, motion 2, density 5) instead of the skill's landing-page baseline.
  • Kept Fraunces and Inter. The skill discourages Fraunces by default, but BRAND.md names it, which is the skill's own override case.
  • One accent (bronze) everywhere, one radius scale (rows 14, cards 16, chips 999), tokens copied from the starter file, no new hex.
  • No card spam: the readiness states are the real card shown four times for comparison, not a new grid. Notes use a full hairline box, never a left-border callout.
  • Estimated weights get their own visual state (grey "~" number, lighter bar) so the difference is visible, not just written.

Stage 2emil-design-eng

  • Decided nothing new moves. Marks, percent numbers, the trademark line and the weights note are static. The PSM switch reloads the page like A+, so it gets no transition.
  • Kept existing motion only: press scale on rows and buttons, the card reveal stagger, the landing plate hover lift and draw-on, the bar sweep.
  • Checked selected states have a second channel: the switcher's active row has a tick, the picker's selected row fills its round check. Colour is never the only signal.
  • Fixed the reduced-motion block: it now keeps opacity and colour fades and removes only the transforms, instead of killing every transition.
  • Hover lifts are gated to fine pointers; on touch the landing CTA text is always shown.

Stage 3transitions-dev

  • Nothing to choreograph, because stage 2 added no motion. Considered and rejected: number pop-in for the percent figure (readiness already has its own update behaviour) and sliding tabs for a PSM I | PSM II toggle (no toggle exists, A+ has none).
  • Checked existing choreography against BRAND.md §6: reveal stagger 60ms steps over 520ms, the brand curve cubic-bezier(0.16, 1, 0.3, 1), entrances never below scale(0.96).
  • No transitions.dev token block pasted, no durations taken from its scale.

Stage 4humanizer

  • Removed bold inline lead-ins from the annotation lists and cut slogan lines ("Mirror, don't invent", "Same plate, real data").
  • Broke up "instead of" pivots into two plain sentences.
  • Kept the trademark lines word for word as approved. Weights note says who doesn't publish what, then what we did, in plain words.
  • No em dashes in copy. The empty-score placeholder is "--" (two hyphens), as the locked card already shows.
  • Wrote "about 60%" in the app (reads naturally) and "~60%" on the landing plate (space is tight).

Stage 5marketing-psychology

  • Goal gradient: below the line, the insight names the distance ("6 points to go"). Above it, it names the margin and the action that protects it ("today's reviews keep you there").
  • PSM's 85% bar gets a normalising line ("the last few points are the slowest to get") so a 79% "Close" doesn't read as failing.
  • Empty state never shows "0%". It uses the existing "Take a quiz to unlock" prompt, a small first step.
  • Trust: saying the weights are estimates is an honest admission that makes the official numbers more believable. The trademark line is neutral and quiet, never placed to look like an endorsement.
  • One CTA label on landing tiles ("Start studying →"), same as the live tiles.
